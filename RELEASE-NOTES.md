# Tetris Atelier v1.0.0

## Changes

Validated versioned JSON/SQLite save and restore of session results and all six settings; complete-file validation precedes effects. Retains the previously delivered capabilities.

## Installation and use

Download tetris.html and open it in a JavaScript-enabled browser, or serve that file with a static HTTP(S) host. No developer runtime is required by players. Verify the download with SHA256SUMS. This is a standalone browser artifact, not a signed or store-distributed desktop package.

## Verification and limits

The phase report records actual pytest rule/adapter checks, packaged-file execution, Canvas/keyboard/lifecycle checks and responsive geometry in isolated Chromium headless shell and Firefox. On this Linux execution host, Firefox requires the diagnosed process-local content-sandbox override for trusted local tests. Native Windows and OS-window behavior were not executed; no full/headed-browser compatibility claim is made.

SQLite requires the pinned CDN JavaScript library at first use. Cookie durability is supported under HTTP(S); browsers may reject direct-file cookies. JSON Schema is included as session.schema.json; validation also checks unique IDs and real canonical UTC instants.
