# Tetris Atelier v0.7.0

## Changes

Session top-ten completed-game results with stable IDs, UTC timestamps and deterministic tie ranking. Retains the previously delivered capabilities.

## Installation and use

Download tetris-v0.7.0.html and open it in a JavaScript-enabled browser, or serve that file with a static HTTP(S) host. No developer runtime is required by players. Verify the download with SHA256SUMS.txt. This is a standalone browser artifact, not a signed or store-distributed desktop package.

## Verification and limits

The phase report records actual pytest rule/adapter checks, packaged-file execution, Canvas/keyboard/lifecycle checks and responsive geometry in isolated Chromium headless shell and Firefox. On this Linux execution host, Firefox requires the diagnosed process-local content-sandbox override for trusted local tests. Native Windows and OS-window behavior were not executed; no full/headed-browser compatibility claim is made.

This release delivers its stated phase scope; the remaining capabilities are scheduled in PLAN and are not claimed delivered.
